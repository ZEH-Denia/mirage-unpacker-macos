# Mirage Unpacker 1.8.1（本机预览）

本版本只安装在本机用于预览，**未提交 Git、未推送、未在 GitHub 发布，也未更新应用内更新 feed**（`updates/appcast.xml` 仍是 1.8.0）。因此不会有任何在线用户看到或收到 1.8.1。

## 相对 1.8.0 的改动

- 静态场景组合的角度单位修正为弧度（此前按角度制处理，导致带旋转的图层几乎不旋转）。
- 脚本/动画绑定的属性改用场景保存的静态默认值，不再因单个绑定而放弃整张组合；条件型用户属性只取保存值，并在提示中标注未求值。
- 旧版百分比不透明度（0–100）归一化；越界值仍回退。
- 图层 `color` 按 RGB 乘性色调绘制；未确认的混合模式仍回退。
- 不透明度与色调按逐层属性处理，父层只提供变换（不再错误地沿父子链相乘）。
- `brightness ≠ 1`、镜像、透视、骨骼锚点等语义未确认的外观属性改为**显式回退**，不再静默忽略，避免“成功但画面错误”。
- 任务提示会报告实际组合的图层数、按静态默认值处理的绑定处数、未求值的条件绑定数、未渲染的非图片对象数、未包含的图层效果数、跳过的引擎内建图层数、应用色调的图层数。

完整说明与支持矩阵见 [SCENE-COMPOSITION-IMPROVEMENTS.md](SCENE-COMPOSITION-IMPROVEMENTS.md)。

## 本机验证

- 对本机工坊内容中 27 个真实场景做了只读结构普查；5 个结构不同的场景做了改动前后渲染对照。目标真实场景的静态预览与 1.8.0 输出**逐字节相同**；两个此前无法组合的真实场景现在可以组合。
- 自动回归：单元测试 161 项、多层渲染 27 项、场景语义 58 项、图片冲突 11 项、队列集成 10 项、合成/真实场景队列各 5 项，回归脚本 7 个阶段通过。
- **没有播放器实际运行画面参考**，因此不承诺与播放器逐像素一致；静态预览仍是实验性结果。

## 已知限制

- 图层效果（模糊、遮罩、摇摆、音频条等）未应用；文本/时钟、粒子与音频不渲染；脚本与动画不逐帧执行。
- 条件型用户属性不求值；`disablepropagation`、复杂分组淡出未处理；3D 透视与绕 X/Y 旋转回退。
- 8192×8192 纹理、上千对象等极端输入未逐一测。

## 安装与回滚

- 本机安装位置 `/Applications/PKD.app`，bundle ID 保持 `com.zeh.pkd`，仍是 ad-hoc 签名、不做 Apple 公证。
- 安装只替换程序本体，不修改用户偏好或素材库；升级前已备份 1.8.0 的 app 与偏好，位于 `~/Documents/Codex/Backups/`（目录名含 `pkd-1.8.1-install-` 的那一份）。
