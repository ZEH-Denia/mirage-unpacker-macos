# Mirage Unpacker 1.8.2

1.8.2 已作为正式版本发布在 GitHub（DMG 分发，ad-hoc 签名，**不做 Apple 公证**），并同步更新应用内 Sparkle 更新 feed。GitHub 上此前的 latest 是 1.8.0，1.8.1 未公开发布。

## 相对 1.8.0 的用户可见变化

### 场景壁纸的静态组合预览

- 角度单位按场景数据实际使用的**弧度**处理（此前按角度制，导致带旋转的图层几乎不旋转）；脚本/动画绑定的属性改用场景保存的静态默认值，条件型用户属性只取保存值并标注未求值。
- 旧版百分比不透明度（0–100）归一化；图层 `color` 作为 RGB 乘性色调绘制；不透明度与色调按**逐层**属性处理，父层只提供变换。
- **puppet 骨骼蒙皮（默认静态姿态）**：解析模型里的骨骼与动画，按引用的动画第 0 帧计算姿态后绘制角色；无法确认的结构（异常父链、越界骨骼、权重异常、截断、超限、多动画层等）回退到绑定姿态或原始顶点，不猜测坐标。
- 引擎内建图层：纯色层按扁平着色器语义绘制；容器层只绘制其子层；带混合模式的纯色层跳过并计数，而不是按普通叠放画错。
- 任务提示会报告实际组合的图层数、按静态默认值处理的绑定数、未求值的条件绑定数、未渲染的非游戏对象数、未包含的图层效果数、按姿态绘制的 puppet 数等。

**限制**：这是**静态**预览，不执行脚本、不渲染粒子/文本时钟/音频，动画只取第 0 帧。与真实播放器画面**有改善但仍近似**：在相同的无损首帧参考下，本机一组真实场景的平均差从 4.5165 降到 4.1436（>16 像素 5.745%→5.410%）——只是近似程度变好，不是逐像素一致。

### 存储清理更安全

- 删除/移入废纸篓只作用于本应用自己产出的目录与本应用创建、带归属标记的临时目录；未知来源与旧版遗留目录一律**只读**，重新导出也不会接管它们。
- 清理前重新校验真实路径，拒绝符号链接与越界路径；外部目录与用户素材不会被自动删除。
- 此前一次数据事故的**根因仍未确认**，本版本不声称已修复根因，只收紧了可删除范围。

### 界面与操作

- 素材库、侧边栏与结果区的布局重排，窗口尺寸变化时更稳定；键盘与辅助功能标签同步更新。
- 无障碍检查覆盖主要控件的标签与操作路径（**人工 VoiceOver 朗读验收仍待补**）。

### 进程、日志与更新恢复

- 长任务（解包）的进程监控更可靠：应用异常退出时不会留下孤儿引擎进程；取消后不残留临时产物。
- 临时产物集中在专属临时根目录，带归属标记与锁，启动时只回收确实属于本应用且已闲置的目录。
- 日志写入改为并发安全的实现，失败原因（无法启动、权限、磁盘不足、环境不兼容、被强制终止等）在界面提示里分类型展示，不再笼统归为「包已损坏」。
- 更新失败后的恢复状态更明确，避免更新失败后反复提示或卡住。

## 下载与校验

- 安装包：`Mirage-Unpacker-for-macOS-1.8.2.dmg`（约 11 MB），同时用于官网/Release 下载与 Sparkle 应用内更新。
- DMG 的 SHA-256 与 EdDSA 签名见 Release 页面与 `updates/appcast.xml`；更新源的公钥内置于应用中，与发布签名配对。

## 已知限制（与 1.8.0 相同的边界）

- 场景预览仍是实验性的静态近似；效果着色器、粒子、文本/时钟、脚本不执行，动画不随时间演化。
- 本机验证覆盖的是本机可访问的真实场景样本，**不代表所有真实场景都能正确组合**，也不代表所有 macOS 版本都能运行（旧系统真机兼容未验证）。
- 前台交互验收（结果浏览器、存储清理确认、队列筛选、键盘搜索、更新弹窗）、人工 VoiceOver 朗读、真实滚轮手势仍需人工补验。
