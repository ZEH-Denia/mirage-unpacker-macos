# Mirage Unpacker 1.8.0

## 新增

- 导出前分析：详情及批量确认说明模型、纹理和效果资源，并提示可能无法完整组合的情况。
- 应用内结果浏览器：切换导出图片、缩放预览、查看尺寸/格式/体积，以及在 Finder 中定位。
- 重复图片处理：保留两份、跳过或覆盖；每批任务固定规则，队列分别统计新增与跳过数量。
- 队列状态汇总及筛选：快速查看未结束、需处理和已结束的任务。
- 收藏与最近使用：记录保存在本机，最近使用保留最新 100 项；清空最近使用不影响收藏。
- 本地临时导入：拖入壁纸包或文件夹，也可按 ⌘O 打开；同一来源去重，刷新保留，移出不修改来源文件。

## 改进与修正

- 实验性静态组合支持多个普通图片层和 puppet，包括二维位置、缩放、平面旋转、层顺序与整层透明度。
- 修正“清除隐藏选择”误清可见项的问题。
- 开发与测试使用独立占位素材环境，正式应用继续使用用户原有路径及设置。

## 使用说明

临时导入只保留本次会话。静态组合不执行脚本、粒子、时钟或动态效果，也不支持所有 3D、父子层级及未知材质；结果不保证等同于壁纸的实际运行画面，原始图片仍会保留。

应用支持 macOS 14 及更高版本。本次本机安装包为 Apple Silicon DMG，保持现有 ad-hoc 签名方式，不进行 Apple 公证。

开发验证记录见 [DEVELOPMENT-ACCEPTANCE.md](DEVELOPMENT-ACCEPTANCE.md)。
